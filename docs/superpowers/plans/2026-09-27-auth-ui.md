# Auth UI — Implementation Plan

**Spec:** `docs/superpowers/specs/2026-09-27-auth-ui-design.md`

**Goal:** Build every auth screen from Figma section 1077:3. Shared tokens and components drive the styling, and a Next.js BFF sits in front of Mindo-API with the tokens kept in httpOnly cookies.

**Verification:**
- The project has no test runner. Each task ends with `npx tsc --noEmit` and `npm run lint`.
- The final task also runs `npm run build` and a manual smoke test against the BE on `http://localhost:4000`.

## Task 1: Tokens and font
- `src/app/globals.css`:
  - Replace the `:root` values with the Mindo palette.
  - Add `--input-bg`, `--placeholder`, `--destructive-soft`, `--disabled`, `--success`, `--success-soft`, `--shadow-card`, and register them in `@theme inline`.
  - Set `--radius: 1rem`.
- `src/app/layout.tsx`: load Be Vietnam Pro via `next/font/google` as `--font-sans`; set `lang="vi"`.

## Task 2: Shared UI primitives (`src/components/ui`)
- `button.tsx`: add size `xl` (h-14, rounded-2xl, 15px semibold). Make the disabled style use `bg-disabled`. Add a `loading` prop.
- `input.tsx`: h-14, rounded-2xl, `bg-input-bg`, `px-[18px]`, 14px medium, placeholder colour, error border.
- `password-input.tsx` (new): wraps `Input` and adds an eye toggle.
- `checkbox.tsx`: 20px, rounded-md, 1.5px border.
- `input-otp.tsx`: slot variant with 58px cells, a 12px gap, rounded-[14px].
- `segmented-control.tsx` (new).
- `alert.tsx` (new): a destructive-soft banner.

## Task 3: Auth building blocks (`src/components/auth`)
- `auth-card.tsx`, `logo.tsx`, `status-icon.tsx`, `resend-timer.tsx`, `form-field.tsx`, `auth-footer-link.tsx`.
- `src/hooks/use-countdown.ts`.

## Task 4: API layer
- `src/types/auth.ts`, `src/lib/api-error.ts`, `src/lib/axios.ts` (baseURL `/api`, envelope unwrap, ApiError).
- `src/lib/validations/auth.ts` (zod schemas), `src/lib/auth-errors.ts` (code → message/field).
- `src/services/auth.service.ts`.
- Server side: `src/lib/server/backend.ts` (fetch to `API_URL`) and `src/lib/server/session.ts` (cookie helpers).

## Task 5: BFF route handlers and proxy
- `src/app/api/auth/[...path]/route.ts`: a pass-through for the whitelisted public endpoints.
- `src/app/api/auth/login`, `logout`, `refresh`, and `me` route handlers.
- `src/proxy.ts`: guards `/dashboard` and redirects auth pages when a session exists.

## Task 6: Pages
- `src/app/(auth)/layout.tsx`
- `login/page.tsx`: password form and QR panel.
- `register/page.tsx`
- `verify-email/page.tsx`
- `forgot-password/page.tsx`
- `src/app/dashboard/page.tsx`
- `src/app/page.tsx` redirects to `/login`.

## Task 7: QR mock
- `src/services/qr-auth.service.ts`
- `src/components/auth/qr-login-panel.tsx`

## Task 8: Verify
- `npm run lint`, `npx tsc --noEmit`, `npm run build`.
- Run dev, and screenshot `/login`, `/register`, `/verify-email` and `/forgot-password` against Figma.
- Smoke-test the flows against the BE if it is running.
