# Tài khoản của tôi: Implementation Plan

**Spec:** `docs/superpowers/specs/2026-09-27-account-design.md`

**Goal:** Build `/tai-khoan` from Figma 1887:2516 (desktop) and 1889:2606 (mobile), wired to Mindo-API through the BFF. The page includes working dialogs for:
- editing the profile and avatar
- changing the password
- managing devices
- saving preferences

**Verification:**
- There is no test runner. Each task ends with `npx tsc --noEmit` and `npm run lint`.
- The last task also runs `npm run build` and a browser check on :3001 against the BE on :4000.

## Task 1: BFF write support
- `src/lib/server/forward.ts`:
  - `forwardWithSession(request, backendPath, method = "GET")` reads the body once (`arrayBuffer`) for non-GET requests and forwards it with the incoming `content-type`.
  - It keeps `Accept` and the refresh-then-retry logic. The body buffer is reused for the retry.
- `src/app/api/bff/[...path]/route.ts`: per-method whitelists.
  - GET: existing entries plus `account/settings`, `account/sessions`, `referrals/dashboard`, `agency/me`, `me/nfts`.
  - POST: `auth/update-password`, `files/upload`.
  - PATCH: `account/profile`, `account/settings`.
  - DELETE: `account/sessions`, `account/sessions/:id`.
  - One shared handler; export `GET`, `POST`, `PATCH` and `DELETE`.

## Task 2: Types, service, tier mapping
- `src/types/account.ts` holds these types: `AccountDetail`, `AccountSettings`, `AccountSession`, `ReferralDashboard`, `AgencyMe`, `OwnedNft` (only the fields used).
- `src/services/account.service.ts` covers `account`, `settings`, `updateSettings`, `sessions`, `revokeSession`, `revokeAllSessions`, `updateProfile`, `uploadFile` (FormData), `changePassword`, `referrals`, `agency` and `nftCount`.
- `src/lib/agency-tier.ts` holds the tier table (BE thresholds plus the web names) and `tierProgress(total)` → `{ current, next }`.
- `src/lib/validations/account.ts` defines `profileSchema` and `changePasswordSchema`.
- `src/lib/auth-errors.ts` gains the password codes, each mapped to a field and a message.
- `src/types/deposit.ts`: `Account` stays as is. The new detail type goes in its own file.

## Task 3: Tokens and primitives
- `globals.css` gets tokens taken from Figma: `--tier-gold`, `--tier-gold-soft`, `--profile-card` (the gradient stops), `--referral-soft` and `--link`. Register them in `@theme inline`.
- `src/components/ui/switch.tsx` wraps the base-ui Switch (40×24).
- `src/components/account/` gets the shared pieces:
  - `account-card.tsx`: the card shell with a title and an optional action.
  - `setting-row.tsx`: icon tile, title, subtitle and a trailing element. It can be a whole-row button on mobile.
  - `info-field.tsx`
  - `agency-tier-badge.tsx`

## Task 4: Queries
- `src/components/account/use-account.ts`: a React Query hook for each resource, plus shared query keys.
- Mutations invalidate their keys and call `router.refresh()` when the profile or avatar changes.

## Task 5: Cards
- `profile-card.tsx`: avatar with a camera button (upload), name, email, phone, KYC pill, agency tier block, "Chỉnh sửa hồ sơ".
- `referral-card.tsx`: shows the code and a "Sao chép mã" button. On mobile the button sits inline.
- `overview-card.tsx`: three rows.
  - Balance, linking to `/nap-tien`.
  - Peer count, linking to `/peer`.
  - Total commission in VND, with no link.
- `personal-info-card.tsx`: a 2-column grid on desktop and label/value rows on mobile.
- `security-card.tsx`: rows for password, QR and devices. Each row opens its dialog.
- `preferences-card.tsx`: language select (DropdownMenu), email switch and delete-account link.
- Each card handles its own loading skeleton and error state.

## Task 6: Dialogs
- `edit-profile-dialog.tsx`: `full_name`, `phone_number` and `address`, with `PATCH` on submit.
- `change-password-dialog.tsx`
- `sessions-dialog.tsx`: revoke one session; revoke all with a confirmation, then logout and redirect to `/login`.
- `qr-info-dialog.tsx`
- `delete-account-dialog.tsx`

## Task 7: Page and navigation
- `src/app/(app)/tai-khoan/page.tsx` and `account-view.tsx`: the responsive layout, plus `MobileHeader` and a mobile logout button.
- `src/lib/routes.ts` and the `src/proxy.ts` matcher gain `/tai-khoan`.
- `nav-items.ts` adds `PAGE_TITLES` and a `pageTitle(pathname)` helper, used by `AppTopbar` and `MobileHeader`.
- `AppTopbar`: the avatar links to `/tai-khoan`. `AppSidebar`: a "Tài khoản" link above logout.
